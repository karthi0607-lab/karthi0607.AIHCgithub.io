
# MediGram AI - Multilingual Healthcare Assistant

MediGram AI is an AI-powered rural healthcare early screening platform designed to assist rural communities in detecting health risks early, in their own language.

## Features

- **Multilingual Support**: English, Tamil, Hindi.
- **AI Symptom Checker**: Voice-enabled symptom analysis with risk assessment.
- **Read Aloud**: Text-to-speech for results.
- **Emergency Assistance**: Quick access to emergency contacts.
- **Nearby Hospitals**: Integration with Google Maps (simulated).
- **Health Records**: Local storage for symptom history.
- **Responsive Design**: Mobile-first, cleaner UI.

## Tech Stack

- **Frontend**: React + Vite
- **Styling**: Vanilla CSS (CSS Modules / Global Styles)
- **Routing**: React Router DOM
- **Icons**: Lucide React

## Setup & Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Build for Production**:
    ```bash
    npm run build
    ```

## Disclaimer

This platform assists early screening and supports healthcare professionals. It does **not** replace medical consultation.
